# Yacht 주사위 (웹)

주사위 5개, 턴당 최대 3번 굴림, 12라운드로 진행하는 Yacht 게임입니다.
규칙과 AI는 원본을 REA로 분석해서 옮겼습니다. 분석 내용은 [ANALYSIS.md](ANALYSIS.md)에 있습니다.

| 모드 | 설명 | 필요한 것 |
|---|---|---|
| 혼자 (vs AI) | 사람 1명 + AI 1~3명 | 브라우저만 |
| 로컬 멀티 | 한 화면에서 2~4명이 번갈아 플레이 (AI와 섞어도 됨) | 브라우저만 |
| 온라인 멀티 | 방을 만들고 다른 PC에서 참가 (2~4명) | Node.js 서버 1대 |

## 빠른 시작

### 내려받기

```bash
git clone https://github.com/bearstone31/yacht-dice-rea.git
cd yacht-dice-rea
```

git이 없으면 GitHub 페이지의 **Code → Download ZIP**으로 받아 압축을 풀어도 됩니다.

### 혼자 / 로컬 멀티만 할 때 (설치 불필요)

`index.html`을 브라우저(Chrome, Edge, Firefox 등)로 열면 바로 플레이할 수 있어요.

### 온라인 멀티까지 쓸 때

[Node.js](https://nodejs.org) 18 이상을 설치한 뒤:

```bash
npm install     # 처음 한 번 (ws 라이브러리 설치)
npm start       # 서버 실행 → http://localhost:3000
```

같은 네트워크의 다른 PC에서는 서버 창에 표시되는 `http://<서버 IP>:3000`으로 접속합니다.
자세한 내용(방화벽, 포트 변경, 문제 해결)은 아래 [2. 온라인 멀티](#2-온라인-멀티)를 보세요.

### 테스트

```bash
npm test        # 점수 규칙·AI·엔진 테스트 + 실제 서버를 띄운 온라인 통합 테스트
```

## 1. 혼자 / 로컬 멀티

`index.html`을 더블클릭해서 브라우저로 엽니다. 서버가 실행 중이면 `http://localhost:3000`으로 열어도 됩니다.

1. 오른쪽 **혼자 / 로컬 멀티** 탭에서 자리를 1~4개 만듭니다. **+ 자리 추가**를 누르고, 자리마다 **사람/AI**를 고르세요.
2. **게임 시작**을 누릅니다. 차례가 된 사람이 화면을 이어받아 플레이합니다.

조작법(키는 설정에서 바꿀 수 있어요):
- **Space** 또는 **굴리기**: 주사위 굴리기
- 주사위 클릭 또는 **1~5** 키: 고정/해제
- **R** 또는 **모두 해제**: 고정한 주사위를 한 번에 풀기
- 점수표의 미리보기 숫자 클릭: 그 칸에 점수 기록

## 메뉴 (오른쪽 위 버튼)

원본 메인 화면의 설정·친구·전적·도움말 버튼을 옮긴 것입니다(분석은 ANALYSIS.md 마지막 절 참고).
설정, 전적, 친구 목록은 **이 브라우저에만 저장**돼요. 다른 PC나 다른 브라우저로 옮겨지지 않습니다.

| 버튼 | 내용 |
|---|---|
| ⚙️ 설정 | **일반**: 언어(한국어/English), 테마, 도움말 문구, 애니메이션 줄이기, 0점 기록 전 확인<br>**사운드**: 전체/배경음악/인터페이스/효과음 볼륨(기본 40), 음소거<br>**화면**: 밝기, 채도, 대비, 테이블·주사위·눈 색<br>**키 설정**: 굴리기, 모두 해제, 1~5번 고정 키 바꾸기<br>**모든 설정 초기화** |
| 👥 친구 | 온라인 서버에 접속하면 쓸 수 있어요. 아래 "친구 기능" 참고 |
| 🏆 전적 | 게임 수, 승리, 승률, 최고/평균 점수, 요트 횟수, 업적 6종(첫 승리, 100승, 첫 요트, 요트 50회, 345점, 친구와 플레이) |
| ❔ 도움말 | 점수 규칙과 현재 키 설정 |

전적에 들어가는 게임은 혼자(vs AI) 게임과 온라인 게임입니다. 한 화면에서 사람 여러 명이 한 게임은 누구 기록인지 알 수 없어서 넣지 않아요.

소리는 브라우저가 첫 클릭이나 키 입력 이후에만 재생을 허용해서, 페이지를 열고 무언가를 한 번 눌러야 들립니다.

## 2. 온라인 멀티

### 2-1. 서버 실행 (방장 PC 한 대에서만)

필요한 것: [Node.js](https://nodejs.org) 18 이상

```powershell
cd yacht-dice-rea  # 내려받은 폴더
npm install        # 처음 한 번만 (ws 라이브러리 설치)
npm start          # 또는: node server.js
```

실행하면 이런 메시지가 나옵니다.

```
Yacht 서버 실행 중 (포트 3000)
  이 PC:      http://localhost:3000
  같은 네트워크: http://192.168.0.10:3000
종료: Ctrl+C
```

`같은 네트워크` 주소가 다른 PC에서 접속할 주소입니다.
여러 줄이 나오면 공유기에서 받은 주소(보통 `192.168.x.x`나 `10.x.x.x`)를 쓰세요.
`172.x.x.x`는 WSL, Hyper-V, VirtualBox 같은 가상 어댑터일 때가 많습니다.
IP는 `ipconfig` 명령으로도 확인할 수 있습니다(Wi-Fi 또는 이더넷 어댑터의 IPv4 주소).

포트를 바꾸려면:

```powershell
$env:PORT=8080; npm start        # PowerShell
set PORT=8080 && npm start       # cmd
PORT=8080 npm start              # macOS / Linux
```

### 2-2. Windows 방화벽 허용 (처음 한 번)

처음 실행하면 Windows가 **"Node.js JavaScript Runtime의 네트워크 액세스 허용"** 창을 띄웁니다.
여기서 **개인 네트워크**에 체크하고 **허용**을 누르세요.

창을 닫아 버렸거나 다른 PC에서 접속이 안 되면, 관리자 PowerShell에서 다음을 실행합니다.

```powershell
New-NetFirewallRule -DisplayName "Yacht 3000" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow -Profile Private
```

그리고 **설정 → 네트워크 및 인터넷 → (Wi-Fi/이더넷) → 네트워크 프로필**이 **개인**인지 확인하세요.
**공용**이면 위 규칙이 적용되지 않습니다.

규칙을 지우려면:

```powershell
Remove-NetFirewallRule -DisplayName "Yacht 3000"
```

### 2-3. 접속해서 플레이

모든 참가자(방장 포함):

1. 브라우저로 `http://<서버 PC의 IP>:3000`을 엽니다. 서버 PC에서는 `http://localhost:3000`이면 됩니다.
2. **온라인 멀티** 탭에서 서버 주소(자동으로 채워짐)와 이름을 확인하고 **접속**을 누릅니다.

방 만드는 사람:

3. 방 이름과 턴 제한 시간(없음/30/60/90초, 기본 60초)을 고르고 **방 만들기**를 누릅니다.
4. 화면에 나온 **4자리 방 코드**를 다른 사람에게 알려 줍니다.
5. 모두 **준비**하면 **게임 시작**을 누릅니다.

참가하는 사람:

3. **열린 방** 목록에서 **참가**를 누르거나, 방 코드를 입력하고 **참가**를 누릅니다.
4. **준비**를 누르고 방장이 시작하기를 기다립니다.

**⚡ 빠른 매칭**을 누르면 사람이 있는 열린 방에 바로 들어가고, 열린 방이 없으면 새 방을 만듭니다.

### 친구 기능

1. 서버에 접속한 뒤 **👥 친구**를 엽니다. 맨 위에 **내 친구 코드**(6자리)가 있어요. 이 코드는 브라우저마다 고정이에요.
2. 친구 추가 방법은 두 가지예요.
   - 친구 코드를 주고받아 **친구 코드 6자리** 칸에 입력하고 **추가**
   - **접속 중인 사람** 탭에서 **친구 추가**
3. 친구 목록에서 상태를 볼 수 있어요. 오프라인 / 접속 중 / 대기실(방 이름) / 게임 중으로 표시되고, 접속한 친구가 위에 와요.
4. 내가 대기실에 있으면 친구 옆에 **초대** 버튼이 생겨요. 초대받은 사람에게는 화면 오른쪽 아래에 알림이 뜨고, **참가**를 누르면 그 방으로 들어가요.
5. 친구가 대기실에 있으면 **참가** 버튼으로 바로 따라 들어갈 수 있어요.

친구 목록은 서로 따로 관리해요(한쪽만 추가해도 됩니다). 브라우저 데이터를 지우면 친구 코드가 바뀌고 목록도 사라져요.

게임 중 규칙:
- 내 차례에만 굴리기, 고정, 점수 기록을 할 수 있습니다. 주사위는 서버가 굴려서 모두에게 같은 결과를 보여 줍니다.
- 턴 제한 시간이 지나면 **첫 번째 빈 칸에 자동 기록**되고 다음 사람으로 넘어갑니다(원본 게임과 같은 방식).
- 이모지 버튼(👍😂😮😭🔥🙏)으로 반응을 보낼 수 있습니다.
- 끝나면 방장이 **다시 하기**를 눌러 같은 방에서 다시 시작합니다.

연결이 끊겼을 때:
- 같은 브라우저 탭은 자동으로 재접속을 시도하고, 게임 중이면 자리를 되찾습니다.
- 끊긴 동안 그 사람의 차례는 건너뜁니다. 자기 차례에 끊기면 자동 기록됩니다.
- 접속한 사람이 1명만 남으면 게임이 끝납니다.
- 방장이 나가도 게임은 계속되고, 방장 권한은 다음 사람에게 넘어갑니다.

### 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 다른 PC에서 페이지가 안 열림 | 같은 공유기/Wi-Fi에 연결돼 있는지, 방화벽 허용(2-2), 네트워크 프로필이 "개인"인지 |
| 페이지는 열리는데 **접속**이 실패함 | 서버 주소가 `IP:포트` 형식인지(`http://` 없이 써도 됨), 서버 창이 켜져 있는지 |
| 공유기 "게스트 Wi-Fi"에서 안 됨 | 게스트망은 기기끼리 통신을 막는 경우가 많습니다. 일반 Wi-Fi로 연결하세요 |
| `EADDRINUSE` 오류 | 3000 포트를 다른 프로그램이 쓰고 있습니다. `PORT`를 바꿔 실행하세요 |
| 서버 동작 확인 | 서버 PC에서 `http://localhost:3000/health`를 열었을 때 `ok`가 나와야 합니다 |

> 이 서버는 같은 네트워크(LAN)에서 쓰도록 만들었습니다. 계정이나 암호화(HTTPS)가 없으니,
> 공유기 포트포워딩으로 인터넷에 공개하지 마세요.

## 통신 프로토콜 (WebSocket JSON)

클라이언트 → 서버:

```
hello{name, token?, userKey?}  list  create{name?, timer}  join{code}  quick  leave
ready{ready}  settings{timer}  start  again
roll  hold{i}  release  score{index}  emoji{i}
presence{codes[]}  users  invite{code}
```

서버 → 클라이언트:

```
welcome{id, token, friendCode, rejoined?}  rooms{rooms[]}  room{room, you}  error{code}  emoji{from, i}
presence{list[]}  users{list[]}  invite{from, fromCode, room, roomName}  invited{code}
```

`error.code`는 `started`, `full`, `noroom`, `notinroom`, `need2`, `notready`, `notyourturn`, `invite_noroom`, `invite_offline` 중 하나이고, 화면 문구는 클라이언트가 언어에 맞게 붙입니다.

`room.game`에는 전체 게임 상태(점수표, 주사위, 고정, 남은 굴림, 현재 차례)가 들어 있고, `room.remainingMs`는 남은 턴 시간입니다.

## 참고

이 프로젝트는 Yacht 규칙으로 새로 만든 웹 구현입니다. 원본 게임(Steam "Yacht Dice")과 관련이 없고 승인받은 프로젝트도 아닙니다.
원본의 코드, 그래픽, 사운드, 데이터 파일은 들어 있지 않습니다. 화면, 소리, 코드는 모두 새로 작성했습니다.
[ANALYSIS.md](ANALYSIS.md)는 원본 실행 파일을 정적으로 분석해 정리한 구조 설명입니다.
